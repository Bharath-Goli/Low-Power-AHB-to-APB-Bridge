# Low-Power AMBA AHB-to-APB Bridge

This project deals with the RTL design, low-power optimization, and verification of the AMBA AHB-to-APB Bridge in the SystemVerilog language.

Objectives:
Design an AHB-to-APB protocol bridge
Examine clock-gating approaches for lowering dynamic power
Model low-power intent in the Unified Power Format
Verify the bridge implementation by simulation and testbench
Analyze the power, area, and verification coverage

Technologies and Tools:
Verilog / SystemVerilog
RTL Design and Verification
Cadence simulation and synthesis tools
Unified Power Format
Linux

Some results:
Standard design power: 9.62 mW
Low-power design power: 8.89 mW
Power reduction: 7.59%
Standard design area: 1663.50 µm²
Low-power design area: 1687.00 µm²

The project contains source code files, testbenches, and other files related to the implementation of the solution.
